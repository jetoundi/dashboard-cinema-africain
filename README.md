# 🎬 Dashboard Cinéma Africain

> Analyse interactive de 9 739 films africains (1902–2018) — Dashboard HTML/CSS/JS avec Chart.js

**Projet académique** — Master Humanités Numériques · UPHF 2025–2026 · Jeanne Etoundi Ntsama

🔗 **[Voir le dashboard en ligne →](https://jetoundi.github.io/dashboard-cinema-africain)**

---

## 📊 Ce que montre ce dashboard

- **9 739 films** analysés sur 116 ans de cinéma africain
- **19 genres** distincts avec répartition et volume
- **Évolution** de la production par décennie (1900s–2010s)
- **Distribution** annuelle complète (1902–2018)
- **Filtres interactifs** par décennie et par genre

## 🛠️ Technologies

| Outil | Usage |
|-------|-------|
| `HTML5 / CSS3` | Structure et mise en page |
| `JavaScript` | Logique de filtrage et interactivité |
| `Chart.js 4.4` | Visualisations (Doughnut, Bar, Line, PolarArea) |
| `Orange Data Mining` | Analyse exploratoire initiale (EDA) |
| `Python / Pandas` | Nettoyage et préparation des données |

## 🔍 Insights clés

- La **Comédie** (28.5%) et le **Drame** (22.9%) dominent la production africaine
- Explosion de la production à partir des **années 1990** (+66% vs décennie précédente)
- La période **contemporaine (1990–2018)** représente 43% de la production totale
